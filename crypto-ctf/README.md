# CyberQuest Crypto CTF

A browser-based cryptography Capture The Flag, built like the Linux CTF: a real Linux
terminal (v86) with a lite-mode fallback, a warm-up plus 9 missions, tiered paid hints,
a count-up clock and a scoreboard. Topics: encodings, classical ciphers, and hashes.

## Run it
Serve `public/` over HTTP (GitLab Pages, or `cd public && python3 -m http.server`).

## Missions
0 Warm-up (bonus) · 1 Base camp (base64) · 2 Hex marks the spot · 3 Spin cycle (ROT13)
· 4 Hail Caesar (brute force) · 5 Russian doll (layered) · 6 Fingerprints (hashes)
· 7 Letter detective (frequency) · 8 Keyword cipher (Vigenere) · 9 The vault (chained).
2,500 points + 50 bonus.

## Tools (in the terminal)
`caesar`, `freq`, `vigenere` (guest/tools), plus `xxd`, `base64`, `sha256sum`, `tr`.

## Rebuild the VM image
`cd guest && bash build.sh` writes `public/images/quest.cpio.gz`.
Mission text is generated by `guest/make-missions.py` (writes guest/, lite.js, guide.js).

## Deck
`slides/CyberQuest-Crypto-CTF.pptx` (40 slides, fade transitions). Rebuild:
`cd slides && node build-deck-crypto.js`.
