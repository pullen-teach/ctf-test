# Mission 1: Now you see me

Go to your mission folder:

```
cd ~/mission1
```{{exec}}

There is a flag in this folder, but plain `ls` will not show it.
On Linux, any file whose name starts with a dot is **hidden**.

When you have the flag, record it with `submit` and press **CHECK**.

<br>

<details><summary>Hint</summary>

`ls -a` lists **all** files, including hidden ones. One hidden file is a decoy.

</details>
