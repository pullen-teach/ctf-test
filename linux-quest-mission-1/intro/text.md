# Welcome to Linux Quest

You are logged in to a **real Linux server**. Five flags are hidden on it, one per mission.
A flag looks like this: `CYBA{word-1a2b3c4d}`

**How every step works**

1. Read the mission on the left.
2. Find the flag in the terminal on the right.
3. Record it by typing `submit` followed by the flag, for example `submit CYBA{hidden-1a2b3c4d}`
4. Press **CHECK**.

Your prompt should say `player@...`. If it does not, wait a few seconds for the setup to finish.

Every time this scenario starts, the flags and hiding places change.
