Warm-up 2: Speed drills   [optional, 50 bonus points, untimed]

Objective: Practise the keys that make you fast: Tab, the up arrow, Ctrl+C, and copy and paste.

  cd ~/speed
  cat README.txt

Three drills, three pieces of the flag. Each drill needs one keyboard
skill, and each piece is 4 characters.

Drill 1, Tab: cd tab, type cat dri and press Tab. The long file name
finishes itself.

Drill 2, up arrow: run again 5 times within 15 seconds. After the first
one, press up arrow then Enter.

Drill 3, Ctrl+C: run runaway. It never stops by itself. Hold Ctrl and
press C.

Put the pieces together in order: submit CYBA{speed-PIECE1PIECE2PIECE3}.
Copy each piece with the mouse and paste it with Ctrl+V or a right-
click.

When you have the flag: submit CYBA{...}     Stuck? hint 11  (free)
